# Thesis HQ

Thesis is a branding agency helping ambitious startups achieve undeniability.

## Services

- Brand strategy
- Logo & visual identity
- Website design & development
- Social presence auditing

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

Built with Next.js App Router and CSS. The project is intentionally lightweight and ready for deployment on Vercel.
